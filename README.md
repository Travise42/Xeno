This is a small GUI that simulates my homebrew Dungeons and Dragons character, Xeno,'s HUD.

**Who is Xeno?**<br>&nbsp;
Xeno is a robot with a human conscience that must manage their power and their integrity.

**What does this GUI do?**<br>&nbsp;
This interface handles battery power, part integrity, actions, stats on creatures, stats on Xeno, and has a calculator for average damage under different circumstances.

**How is it done?**<br>&nbsp;
This GUI is primarily python and relies on *pygame*. Several inputs use entries from the *pygame_gui* library. Data is stored in json files that will be created upon running the program.
